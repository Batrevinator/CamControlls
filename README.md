# Cam Controls

### What is this?
<p> This system is intended to allow a user to control a videogame character using their webcam. It uses OpenCV to capture video from the webcam, and then applies a series of image processing techniques to isolate the user's hand and track its movement. </p> </br>

<p> Right now the system only does very basic motion tracking to find where the user's hand is. The intention is to later recognize specific hand gestures to allow for more complex controls. </p> </br>
